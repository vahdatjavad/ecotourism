Datasets Overview

We have organized the Southern black-throated finch occurrence and weather station data into the following structured datasets, stored in the data/ directory:

  • southern_black_throated_finch_2024.rda
    Contains Southern black-throated finch occurrence records across all states in Australia.

  • southern_black_throated_finch_2024_ws.rda
    An enhanced version of the occurrence data, merged with the nearest weather station information, including:

    --Station ID (weather_station_id)
--Station name (stname)
--Geographic details (lat.y, lon.y, address, city, state)

  • southern_black_throated_finch_top_weather.rda
    Focuses on weather data from the top 3 most frequently recorded stations associated with Southern black-throated finch occurrences.

  • weather_stations.rda
    A standalone dataset of all unique weather stations in Australia, providing reference metadata for cross-referencing.
